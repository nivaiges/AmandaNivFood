About us

We're Amanda and Niv — a couple who plan trips around restaurants and argue about whether the bread course counts. This is our little corner of the internet where we keep track of everything we eat: the great, the good, and the "never again."

Every entry gets two independent scores out of five stars. The overall score is our average, and that's what decides the rankings. When we disagree by a lot, it's officially a hot debate. 🔥

How we score

  • ★★★★★ Life-changing. Tell everyone.
  • ★★★★★ Excellent. Would happily return.
  • ★★★★★ Solid. Good, not legendary.
  • ★★★★★ Meh. Wouldn't go out of our way.
  • ★★★★★ Nope.

Sync & settings

The blog is a static site on GitHub Pages. To publish entries so they show up for everyone, connect a GitHub token — saving an entry then commits it straight to the repo. Without a token, new entries are saved only in this browser.

How do I get a token?
  1. Go to GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Under Repository access, choose Only select repositories and pick this blog's repo.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate, copy the token, and paste it below. It's stored only in this browser.
